Privacy Policy

อัปเดตล่าสุด: 18 พฤษภาคม 2026

1. ข้อมูลที่เราเก็บ

MuteGPT อาจเก็บข้อมูลที่ผู้ใช้กรอกหรือสร้างขึ้นระหว่างใช้งาน เช่น ชื่อ ชื่อเล่น อีเมล วันเกิด เวลาเกิด สถานที่เกิด เพศ สถานะความสัมพันธ์ ข้อมูลคนคุยหรือแฟน ประวัติการสนทนา ผลคำทำนาย ไพ่ที่เลือก ตัวเลขที่วิเคราะห์ และข้อมูลการใช้งานพื้นฐานของระบบ เช่น จำนวนครั้งในการใช้งานแต่ละหมวดและเวลาที่ใช้งาน

2. ข้อมูลของบุคคลอื่น

บางฟีเจอร์อาจให้ผู้ใช้กรอกข้อมูลของบุคคลอื่น เช่น วันเกิดของแฟน คนคุย หรือบุคคลที่เกี่ยวข้อง ผู้ใช้รับรองว่าตนมีสิทธิ์ ได้รับอนุญาต หรือมีเหตุอันชอบด้วยกฎหมายในการนำข้อมูลดังกล่าวมาใช้กับระบบ และผู้ใช้ควรหลีกเลี่ยงการกรอกข้อมูลที่ละเอียดอ่อนเกินความจำเป็น

3. เราใช้ข้อมูลเพื่ออะไร

ข้อมูลถูกใช้เพื่อยืนยันตัวตน สร้างคำทำนายเฉพาะบุคคล แสดงประวัติย้อนหลัง ป้องกันการใช้งานเกินโควตา ปรับปรุงคุณภาพระบบ และตรวจสอบปัญหาทางเทคนิค

4. บริการภายนอกที่เกี่ยวข้อง

ระบบใช้ Supabase สำหรับ Authentication และฐานข้อมูล, Vercel สำหรับให้บริการหน้าเว็บและ API Gateway, Render สำหรับ Python FastAPI backend และ Gemini API สำหรับสร้างคำตอบจาก AI ข้อมูลบางส่วนอาจถูกส่งไปยังบริการเหล่านี้เท่าที่จำเป็นเพื่อให้ระบบทำงานได้

5. การส่งข้อมูลไปยัง AI

เมื่อผู้ใช้ขอคำทำนายหรือสนทนากับ AI ระบบอาจส่งข้อมูลที่เกี่ยวข้อง เช่น วันเกิด เวลาเกิด สถานที่เกิด สถานะความสัมพันธ์ คำถาม ประวัติการสนทนา ไพ่ที่เลือก หรือตัวเลขที่ต้องการวิเคราะห์ ไปยัง Gemini API เพื่อสร้างคำตอบ ผู้ใช้ไม่ควรส่งข้อมูลลับ ข้อมูลอ่อนไหว หรือข้อมูลที่ไม่ต้องการให้ประมวลผลโดยบริการ AI ภายนอก

6. การโอนหรือประมวลผลข้อมูลในต่างประเทศ

ผู้ให้บริการภายนอกบางราย เช่น Supabase, Vercel, Render และ Google อาจจัดเก็บหรือประมวลผลข้อมูลบนเซิร์ฟเวอร์ที่ตั้งอยู่นอกประเทศไทย การใช้งานระบบถือว่าผู้ใช้รับทราบว่าข้อมูลอาจถูกส่งหรือประมวลผลผ่านโครงสร้างพื้นฐานของผู้ให้บริการเหล่านี้ตามเงื่อนไขของแต่ละบริการ

7. การเก็บรักษาและการลบข้อมูล

เราจะเก็บข้อมูลบัญชี โปรไฟล์ ประวัติการสนทนา และผลคำทำนายตราบเท่าที่จำเป็นต่อการให้บริการ การแสดงประวัติย้อนหลัง การควบคุมโควตา และการดูแลระบบ หรือจนกว่าผู้ใช้จะลบข้อมูลหรือขอให้ลบข้อมูลตามขั้นตอนที่ระบุในหน้า Data Deletion

8. สิทธิของผู้ใช้

ผู้ใช้สามารถติดต่อผู้พัฒนาเพื่อขอเข้าถึงข้อมูล ขอแก้ไขข้อมูล ขอถอนความยินยอม ขอคัดค้านหรือจำกัดการใช้ข้อมูล และขอลบข้อมูลส่วนบุคคลได้ตามขอบเขตที่กฎหมายคุ้มครองข้อมูลส่วนบุคคลกำหนด โดยผู้พัฒนาอาจต้องตรวจสอบตัวตนก่อนดำเนินการตามคำขอ

9. ความปลอดภัย

เราใช้ระบบยืนยันตัวตนและสิทธิ์การเข้าถึงของ Supabase เพื่อจำกัดการเข้าถึงข้อมูลของผู้ใช้ อย่างไรก็ตาม ผู้ใช้ควรหลีกเลี่ยงการส่งข้อมูลที่ละเอียดอ่อนเกินความจำเป็น เช่น เลขบัตรประชาชน รหัสผ่าน ข้อมูลบัญชีธนาคาร หรือข้อมูลส่วนตัวของบุคคลอื่นโดยไม่ได้รับอนุญาต

10. การเปลี่ยนแปลงนโยบาย

นโยบายนี้อาจมีการปรับปรุงตามการพัฒนาระบบ หากมีการเปลี่ยนแปลงสำคัญ เราจะปรับวันที่อัปเดตและเนื้อหาในหน้านี้
